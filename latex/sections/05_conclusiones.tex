De este análisis preliminar se desprende que C-Lock representa un enfoque prometedor
para reducir el consumo energético en sistemas embebidos multicore, aprovechando
hardware dedicado en lugar de depender del software del sistema operativo.

Los principales desafíos para la implementación del simulador son:
\begin{itemize}
    \item Modelar con precisión el comportamiento del clock-gating.
    \item Definir un modelo de energía representativo.
    \item Reproducir condiciones de contención similares a las del paper.
\end{itemize}
